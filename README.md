# Sort IT

Локальное Windows-приложение для проверки фотоколлекции и создания плана сортировки с Ollama.

## Запуск готовой сборки

1. Скачайте SortIT.exe из Releases и запустите двойным щелчком.
2. Откроется браузер по адресу http://127.0.0.1:8765/.
3. Выберите папку и задачу.

Python, Pillow, HEIF, NumPy, OpenCV, Tcl/Tk, HTML, CSS и шрифт Oswald включены в EXE.
Ollama и модель в сборку не включены. Этот выпуск настроен для компьютера владельца:

- Ollama: `Q:\AI\Ollama\Ollama\ollama app.exe`
- Модели: `Q:\AI\Ollama\ollama-models`
- Модель: `qwen3.5:9b`

При запуске приложение проверяет Ollama и запускает установленный экземпляр при необходимости.
Модель не скачивается повторно. На другом ПК пути меняются в `setup_tools.py` перед сборкой.
Настройки и журнал запуска хранятся в `%LOCALAPPDATA%\Sort IT`.
Процесс работает до завершения через Диспетчер задач. Закрытие вкладки оставляет локальный сервер запущенным.
Повторный запуск EXE открывает уже работающий экземпляр.

Очистка создаёт отчёт и обзор. Оригиналы удаляются безвозвратно только после выбора и подтверждения в обзоре.
План сортировки сохраняет категории в CSV. Просмотр и удаление кандидатов доступны через кнопку «Обзор».

## Запуск исходников

Установите 64-битный Python 3.10 или новее, затем выполните из каталога проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

## Сборка EXE

В PowerShell откройте каталог проекта и запустите `powershell -ExecutionPolicy Bypass -File .\build.ps1`.
Скрипт создаст отдельное окружение и `dist\SortIT.exe`.
Сборку Windows выполняют на Windows. Интернет нужен при установке зависимостей для сборки.

## Публикация на GitHub

1. Создайте новый пустой репозиторий SortIT на github.com.
2. Загрузите содержимое исходного архива в репозиторий, включая app_resources и .gitignore.
3. В Releases нажмите Draft a new release, задайте тег v1.0.0 и прикрепите SortIT-Windows.zip.
4. Опубликуйте релиз. EXE хранится в Releases, исходники — в репозитории.

Фотографии, отчёты, личные настройки, модели и виртуальные окружения в исходный архив не включены.
Исходный код Sort IT распространяется по MIT. Шрифт Oswald — SIL OFL, текст лицензии в app_resources/OFL-Oswald.txt.
Сторонние библиотеки сохраняют собственные лицензии. Сведения находятся в THIRD_PARTY_NOTICES.md.
EXE не подписан сертификатом издателя, поэтому Windows может показать уведомление SmartScreen.
